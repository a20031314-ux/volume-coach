1. 처리하는 정보

볼륨 코치(이하 '앱')는 운동 추천과 기록에 필요한 정보만 처리합니다. 별도 가입 없이도 쓸 수 있으며, 이 경우 모든 정보는 사용자의 휴대폰에만 저장됩니다.

• 운동·식단·신체 정보: 운동 기록(종목, 세트, 무게, 횟수, 시각), 루틴, 식단 기록, 나이·성별·키·체중·체지방률·골격근량 등 사용자가 입력한 값

• 위치 정보: 사용자가 러닝·걷기·등산 기록을 시작한 동안의 GPS 위치(경로, 거리, 속도, 고도). 기록을 시작하지 않으면 위치를 수집하지 않으며, 앱이 백그라운드에서 따로 위치를 수집하지 않습니다. '지금 이동 속도' 기능은 화면을 보는 동안만 위치를 사용하고 저장하지 않습니다.

• 건강 데이터: 사용자가 연결을 켠 경우에 한해 iPhone 건강 앱 또는 Android 헬스 커넥트에서 걸음 수와 걷기·달리기 거리를 읽습니다. 이 정보는 휴대폰 안에서 화면 표시와 활동량 계산에만 쓰며 서버로 보내지 않습니다.

• 계정 정보: 회원가입을 한 경우 이메일 주소와 암호화된 비밀번호

2. 이용 목적

• 운동 추천, 회복 계산, 주간 볼륨과 하루 활동량 표시

• 러닝 거리·속도·경로·고도 계산과 칼로리 추정

• 회원가입한 경우 여러 기기 사이의 기록 동기화와 백업

광고, 마케팅, 프로필 분석에는 사용하지 않으며 판매하지 않습니다.

3. 보관과 저장 위치

• 가입하지 않은 경우: 휴대폰에만 저장되며 앱을 삭제하면 함께 지워집니다.

• 가입한 경우: 운동·식단·신체·러닝 기록(경로 포함)과 설정이 Supabase(서버 위치: [Supabase 리전 — 예: 대한민국 서울])에 저장됩니다. 계정을 삭제하면 즉시 지워집니다.

• 건강 앱·헬스 커넥트에서 읽은 걸음 수는 서버에 저장하지 않습니다.

4. 외부 서비스

• Supabase: 회원가입한 경우 계정과 기록 저장 (데이터 처리 위탁)

• Open-Meteo: 러닝·걷기·등산 기록을 저장할 때 고도와 날씨를 계산하기 위해 경로의 좌표(위도·경도)를 보냅니다. 사용자 계정이나 이름 등 다른 정보는 보내지 않습니다.

• OpenFreeMap(OpenStreetMap): 지도를 표시하기 위해 지도 이미지를 내려받습니다. 위치 기록은 보내지 않습니다.

• Expo: 앱 업데이트 파일을 내려받습니다.

• Anthropic(Claude API): 사용자가 'AI로 영양정보 찾기'를 누른 경우에 한해 입력한 음식 이름을 보내 웹 검색으로 영양정보를 찾습니다. 계정·기록·위치 등 다른 정보는 보내지 않습니다. 찾은 영양정보(음식 이름과 수치, 출처)는 다른 사용자도 쓸 수 있도록 서버에 저장되며, 누가 검색했는지는 공개되지 않습니다.

5. 사용자의 권리와 삭제

• 앱 안에서 기록을 개별 삭제할 수 있습니다.

• 설정 → 계정 → 계정 삭제를 누르면 서버에 저장된 계정과 모든 기록이 즉시 삭제됩니다.

• 설정 → 앱 정보 → 이 기기의 기록 모두 지우기로 휴대폰에 저장된 기록을 지울 수 있습니다.

• 앱을 쓸 수 없는 경우 아래 문의 이메일로 계정 삭제를 요청하면 7일 이내에 처리합니다.

• 위치·건강 데이터 권한은 휴대폰 설정에서 언제든 끌 수 있습니다.

6. 안전성 확보 조치

• 서버 통신은 암호화(HTTPS)되며, 서버의 각 기록은 본인 계정만 읽고 쓸 수 있도록 접근 규칙(행 수준 보안)을 적용합니다.

• 비밀번호는 암호화되어 저장되며 운영자도 알 수 없습니다.
