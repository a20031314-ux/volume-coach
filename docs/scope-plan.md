# 기능 범위 · 기본 흐름 · 옵션 정리

> 2026-11-09. 코드 기준 `6b1e923`. 지금까지 붙인 기능을 "상위 기능 → 기본 흐름 → 옵션" 3단으로 다시 묶은 안.
> 결정이 필요한 곳은 **[결정 N]**. 결정 후 이 문서를 고치고 MY 설정·화면 정리를 진행.

## 0. 왜 다시 정리하나
- 기능이 생길 때마다 같은 층위에 붙음 → MY "운동" 그룹 8줄, "나" 그룹에 식단 설정 3줄, 유산소 옵션 시트에 목표 페이스와 페이스메이커가 따로.
- 같은 목적의 기능이 두 개씩 있음(목표 페이스 ↔ 페이스메이커, 휴식 타이머 ↔ 가이드 휴식 안내).
- 이름이 겹침: "기능 설명"(`/guide`)과 "가이드 모드".
- 원칙(main.md 2절)은 이미 있음: **루틴 > 오늘 할 일 > 옵션**, 옵션을 같은 층위에 늘어놓지 않기, 기능 추가보다 구체화.

## 1. 앱이 하는 일 — 상위 기능 4개 + 기반 1개

| 상위 기능 | 사용자가 묻는 것 | 화면 |
|---|---|---|
| **① 계획** | 오늘 뭐 하지? | 오늘 탭 |
| **② 운동하기** | 지금 하는 운동을 어떻게 기록하지? (웨이트 · 유산소) | 오늘 → 세션, 유산소 탭 |
| **③ 먹기** | 뭘 얼마나 먹지? | 영양 탭 |
| **④ 돌아보기** | 잘 되고 있나? | 기록 탭, MY 추세 카드 |
| 기반: **나** | (앱이 나를 알아야 하는 것) 목적·일정·장비·몸·생활 시간 | MY 탭 |

**범위 밖(안 하는 것) 제안:** 다른 사용자와 공유·랭킹, 사진으로 음식 인식, 실시간 심박(웨어러블), 코치와 대화형 채팅, 식단 배달·쇼핑 연결.

## 2. 상위 기능별 정리

표기: **기본** = 설정 없이 모든 사용자가 타는 흐름 · **옵션** = 켜는 사람만(설정 한 곳에서) · **⏸ 보류 후보** = 출시 범위에서 빼거나 숨길 수 있는 것

### ① 계획 (오늘 탭)
- **기본:** 목적·운동 일정 고르기(MY 시작하기 카드) → 오늘 할 일(규칙 추천: 부위당 주 세트·회복) → 권장 무게가 붙은 운동 목록 → 시작
- **옵션:**
  - 루틴형(정해진 루틴으로 오늘 할 일 대체)
  - 중량 프로그램(벤치·스쿼트·데드·OHP 하나를 6~16주) — 루틴형의 한 종류로 묶기 **[결정 6]**
  - 할 수 있는 운동(장비 체크리스트)
  - 운동 규칙 숫자(주 세트 범위·종류 수·휴식일)
  - 오늘 조정 시트(컨디션·다른 날·추가 부위)
- ⏸ 코치 추가 블록(기능성 15분·스트레칭) — 아직 설계만

### ② 운동하기 — 웨이트 (세션)
- **기본:** 시작 → 운동 펼침(권장 무게 채워짐) → 세트 완료 → 휴식 타이머 → 끝 → 결과
- **옵션:**
  - 기록 방식: 운동별 / 세트별 / RPE
  - **진행 방식: 직접 기록 / 음성 가이드(설계 → 끝까지 진행 → 기록 확인)** — 지금은 세션 화면 위 띠로 따로 들어감. 세션 시작할 때 고르는 한 가지로 **[결정 3]**
  - 자동 종료(기본 끔)
- 가이드 세부(템포·자세 잡는 시간·이동 시간·카운트다운·진동)는 가이드 설정 안으로만

### ② 운동하기 — 유산소
- **기본:** 종류(러닝·걷기·등산·자전거·실내) → 시작 → 일시정지/종료 → 저장(거리·시간·페이스·칼로리 자동)
- **옵션:**
  - **목표 하나로 통합 [결정 1]:** 없음 / 목표 페이스 / 페이스메이커(직접 설계) / 지난 기록 — 지금은 목표 페이스(옵션 시트)와 페이스메이커(대기 화면 줄)가 따로
  - 인터벌
  - 음성 안내 상세(1km·N분마다), 단위(페이스/속도), 카운트다운, 화면 켜두기 → 지금처럼 "옵션 ›" 시트
- ⏸ 스프린트(30~400m) **[결정 7]**
- 실내·기타 유산소는 기본 흐름 안(종류 중 하나)

### ③ 먹기 (영양 탭)
- **기본:** 목표 kcal·단백질 자동(목적·몸 기반) → + 음식 추가(최근·자주 먹는 음식 먼저) → 남은 kcal·단백질
- **옵션:**
  - 식단 추천(끼니 시간마다 추천·알림, 없으면 대체 식단)
  - 고정식단(영양제·과일·견과 체크리스트 + 시간 추천)
  - 치팅데이·상쇄
- 음식 추가 시트 안의 보조 기능(옵션 아님, 그냥 도구): 대체 식단, 식사 코스, 프랜차이즈, 직접 입력
- ⏸ AI 메뉴 검색(서버 배포 전까지 숨김), 영양제 브랜드·제품 세부 **[결정 7]**
- 식습관 리포트는 ④ 돌아보기로 이동(영양 헤더 버튼 → MY 영양 추세 카드) **[결정 5]**

### ④ 돌아보기 (기록 탭 · MY 추세)
- **기본:** 하루 타임라인(운동·러닝·걷기, 시간순) + 맨 위 "소모 vs 섭취" 한 줄
  - ❗ 식사가 타임라인에 아직 안 들어감 → 넣어야 "하루 전체"가 됨
- **더 보기(옵션 아님, 누르면 열림):** 하루 회고, 운동·러닝 상세(지도·구간·경사·페이스메이커 결과), 주간 볼륨, 추세 카드 4장(몸·근력·주 세트·단백질), 식습관 리포트

### 기반: 나 (MY)
- **필수 2개:** 목적, 운동 일정 — 고르기 전엔 추천·영양 목표를 계산하지 않음(지금 그대로)
- **선택:** 경력·성별·나이, 장비, 몸 정보(인바디), 걸음 수 연동, 계정 동기화
- **생활 시간 한 곳으로 [결정 4]:** 기상·취침·끼니 시간·평소 운동 시간. 지금 끼니 시간은 "식단 추천" 안에, 운동 시간은 기록에서 추정, 취침은 고정식단에서 추정 → 고정식단 시간 추천·식단 추천·카페인 경고가 모두 이걸 씀

## 3. 겹침 · 충돌 (결정 목록)

| # | 지금 | 제안 |
|---|---|---|
| 1 | 목표 페이스(옵션 시트) + 페이스메이커(대기 화면) 따로 | 유산소 대기 화면 **"목표" 한 줄**: 없음 / 페이스 / 페이스메이커 / 지난 기록 |
| 2 | "기능 설명"(`/guide`)과 "가이드 모드" 이름 겹침 | 가이드 모드 → **"음성 가이드"**, 기능 설명은 그대로 |
| 3 | 세션 화면 위 "가이드로 쭉 하기" 띠 + 세트 완료 버튼 | 세션 시작 시 **진행 방식 선택**(직접 기록 / 음성 가이드), 기본은 직접 기록 |
| 4 | 끼니 시간은 식단 추천 안, 운동·취침 시간은 추정 | MY "나"에 **생활 시간** 한 곳 |
| 5 | 식습관 리포트가 영양 탭 헤더 | ④ 돌아보기(MY 영양 추세 카드)로 |
| 6 | 중량 프로그램이 MY 운동 그룹·추세 카드 두 곳 | ① 계획의 "운동 방식"(규칙형 / 루틴형 / 중량 프로그램) 안으로 |
| 7 | 스프린트·AI 메뉴 검색·영양제 브랜드 | 출시 범위에서 **숨김(설정 → 앱 → 실험 기능)** 또는 유지 |

## 4. MY 설정 재배치 안
규칙: **그 화면에서만 의미 있는 옵션은 그 화면의 시트**(유산소 옵션·가이드 설계), **여러 화면에 영향 주는 것만 MY**.

| 그룹 | 줄 |
|---|---|
| 나 | 목적·일정 · 내 정보(경력·성별·나이) · 몸 정보 · 생활 시간 · 할 수 있는 운동(장비) |
| ① 계획 | 운동 방식(규칙형 / 루틴형 / 중량 프로그램) · 운동 규칙 · 운동 목록 |
| ② 운동하기 | 기록 방식 · 음성 가이드 · 걸음 수 연동 |
| ③ 먹기 | 식단 추천 · 고정식단 · 치팅데이 |
| 계정 · 앱 | 계정 · 기능 설명 · 실험 기능 · 앱 정보 |

추세 카드 4장(④)은 지금처럼 MY 맨 위, 설정 목록 위.
