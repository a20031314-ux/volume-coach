## 1. 한 줄 요약
규칙(부위당 주간 세트 범위·운동 종류 수·휴식일) 기반으로 그날 운동을 추천하고, 웨이트·러닝·걷기를 하루 타임라인으로 기록하는 앱. Expo(React Native) + Supabase.

## 2. 사용자와 원칙
- 사용자: 웨이트 2년+, 주 6일+, 바이브코딩으로 서비스 출시 경험. Android·iPhone 둘 다 사용.
- 운동 방식: "부위당 주 12~18세트, 부위당 2종류 이상, 같은 부위 하루 이상 휴식"을 대원칙으로 두고 상황에 따라 자유롭게 조정.
- **모든 것은 선택지로.** 규칙형(자율 추천)과 루틴형(정해진 루틴) 둘 다 제공. 수면·컨디션 같은 신호도 끌 수 있게.
- **UI 층위 원칙.** 루틴 > 오늘 할 일 > 옵션. 옵션을 같은 층위에 늘어놓지 않는다. 의미 없는 설명 문구 금지.
- 타임라인 층위: **하루 전체 타임라인 > 하위(웨이트: 운동 → 세트 / 러닝: 시작 → 시간대별 속도 → 끝)**.
- 방향: 기능 추가보다 **한정된 기능의 구체화**. 빠른 출시.

| 웨이트 세션 | 시작 → 운동별 → (옵션) 세트별 → 끝. 휴식 타이머, 자동 종료(기본 끔) |
| 기록 탭 | **하루 회고**(소모 vs 섭취, 운동 요약, 소모 칼로리 구성, 섭취 영양 대비 목표, 자동 메모, 한 줄 회고) · 하루 타임라인(24시간 막대 + 시간순 항목) → 웨이트/러닝/걷기 상세. 15분 단위 걸음 막대(건강 데이터), 지금 이동 속도(화면 보는 동안만). 주간 볼륨 |
| 유산소 | 러닝·걷기·등산·**자전거**(GPS, km/h, MET 속도표로 칼로리), **실내·기타 유산소**(수영·계단·실내 사이클·로잉·줄넘기·케틀벨·HIIT·구기 등 21종: 강도 3단계 × 시간 × 체중 MET 계산, 기계 칼로리 있으면 그 값, 타이머 또는 직접 입력, 다리 부담은 러닝 km 환산으로 회복에 반영. `kind:'other'` Run으로 저장 → DB 변경 없음), 러닝 자유/인터벌/**스프린트**(30~400m, GPS 맞춘 뒤 카운트다운 → "출발" 음성부터 시간 측정, 목표 거리에서 자동 저장, 거리별 최고 기록), 카운트다운, 음성 안내, 실시간 속도 그래프(1/3/5분, 목표 띠, 이탈 알림), 화면 켜두기, 페이스/속도 단위 |
| 기록 상세(러닝) | 스프린트는 기록·최고 속도(지점)·10m(200m 이상은 50m) 구간별 속도 막대. 지도(경사 색) ↔ 그래프 서로 짚기, 구간 드래그 확대·km/인터벌 구간 선택, 고도·오르막, 경사 보정 페이스, 날씨 |
| 중량 프로그램 | 설정 → 중량 프로그램. 벤치·스쿼트·데드·오버헤드 중 하나, 현재 1RM(기록에서 추정 또는 입력) → 목표, 6~16주·주 1~3회. 4주 단위(3주 증가 + 1주 가볍게), 마지막 주 테스트. 지난 세션 결과로 무게 자동 조정(2회 연속 실패 시 하향). 목표 현실성 표시(월 +% 기준). 회복되면 오늘 할 일 맨 위에 들어가고 세션에 무게×횟수가 채워짐 |
| 운동 목록 | 기본 74종 + 변형·기능성 124종(디클라인/스포토/라슨, 펜들레이/실 로우, 푸시프레스/Z프레스, 퍼즈/박스/SSB 스쿼트, 스모/트랩바/랙풀, 클린·스내치, 케틀벨 스윙·겟업, 캐리·플랭크 등). 변형은 직접 고르면 기록 가능, 추천에는 한 번 해봤거나 즐겨찾기한 것만 들어감 |
| 권장 무게 | 기록에서 운동별 추정 1RM(Epley, 12회 이하) → 반복 범위 하단 + 2회 여유 기준 무게. 기록 없는 운동은 주요 리프트 비율(예: 인클라인 바벨 = 벤치×0.8, 덤벨은 한 손)로. 오늘 할 일 각 줄에 표시 |
| 영양 | 목표 칼로리·단백질(제지방량 기반), 음식 기록. 음식 127종(`src/lib/foods.ts`, 단백질·탄수·과일·채소·지방·유제품·한식외식·간식 분류, g/개/공기 단위로 양 입력). **대체 식단**(`src/lib/swap.ts`): 주 영양소를 한 음식으로 맞추고 모자란 지방·탄수·단백질을 기름·밥·계란 등으로 채움, ±12% kcal·±15% 단백질 안만 표시, 메인 음식 직접 선택 가능, 등푸른 생선 → 오메가3 안내. 먹은 음식 "바꾸기", 저녁(17시~)엔 남은 단백질 한 끼 채우기 제안. **내 식습관**(영양 탭 오른쪽 위, `src/lib/diet-report.ts`): 1/4/12주, 자주 먹는 음식·단백질 공급원·주식 탄수화물 비율·끼니별 단백질·운동일 vs 휴식일 단백질(목표 대비), 눈에 띄는 패턴만 한 줄씩. 2일 이상 먹은 음식은 대체 식단·단백질 채우기에서 먼저 나옴. 기록 5일 미만이면 진행도만. **식단 추천**(설정 → 식단 추천, `src/lib/meal-plan.ts`·`src/store/meal-reminders.ts`): 끼니 시간(1~6개, 30분 단위)마다 로컬 알림 + 영양 탭 맨 위 "다음 끼니" 카드. 그 시간대에 자주 먹는 단백질·주식으로 남은 목표 ÷ 남은 끼니만큼 구성(기록 없으면 닭가슴살·흰쌀밥 등 기본), "없음" 누르면 그 음식만 대체 식단으로 교체(그날만 기억, 되돌리기 가능). 알림은 7일치 예약, 음식 기록·앱 열 때 다시 계산. 웹에선 알림 없음 |
