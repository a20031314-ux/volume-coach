# 탭 UI 정리 설계 (오늘·영양·유산소·기록)

> 2026-11-07. 코드 기준(`5f692e7`)으로 지금 화면을 보고 정리. 구현 전. MY 탭은 `docs/coach-plan.md` 5절.

## 1. 공통 규칙 — 모든 탭은 3층
| 층 | 내용 | 규칙 |
|---|---|---|
| 1 요약 | 그 탭의 핵심 숫자 1~2개 + 막대 하나 | 누르면 세부 숫자·계산 근거가 펼쳐짐. 상태(치팅·상쇄·디로드 등)는 별도 카드 대신 요약 아래 **칩**으로 |
| 2 지금 할 일 | **카드 하나만** | 여러 개면 우선순위 1등만 보이고 "외 N개 ›". 코치 제안·힌트·추천이 모두 이 자리를 놓고 경쟁 |
| 3 목록/타임라인 | 줄마다 이름 + 숫자 하나 | 탄단지·% 같은 보조 숫자와 버튼(바꾸기·삭제)은 줄을 눌렀을 때만 |

- **입력은 시트로.** 화면에 폼을 펼쳐 두지 않는다. 화면 아래 버튼 하나(+ 음식 추가 / 운동 시작 / 시작) → 시트.
- **경고는 아이콘 + 한 줄.** 설명 문장("하루 체중이 1~2kg 늘어도…")은 세부(시트) 안으로.
- **보조 숫자는 기본 숨김.** 한 줄에 숫자는 하나. 예: 음식 줄 = kcal만, 운동 줄 = 세트 + 권장 무게만(이미 그렇게 되어 있음).
- **별도 카드였던 기능은 기존 구조에 흡수.** 고정식단 → 타임라인의 체크 줄, 다음 끼니 추천 → 타임라인의 흐린 줄 + 2층 카드, 주간 볼륨·식습관 → MY 추세 카드.
- 우선순위(2층): 안전·되돌릴 수 없는 것 > 지금 시간에 걸린 것 > 제안 > 정보.

## 2. 영양 탭 (가장 시급)
**지금(위→아래):** 날짜 → 목표 카드(막대 4개 + 끼니 범례 + 계산 근거) → 고정식단 카드(전체 목록) → 치팅 게이지 카드 → 상쇄 진행 카드(여러 개) → 상쇄 제안 카드(선택지 2~3개 + 설명) → 다음 끼니 카드 → 단백질 채우기 후보 → 음식 추가 폼(검색·분류·브랜드·음식 목록·직접 입력·양·미리보기·출처·버튼 2개) → 먹은 음식(끼니마다 탄단지 % 줄 + 경고, 음식마다 탄단지 g + 버튼 2개).

**바꾼 뒤:**
1. **요약 카드**: `남은 kcal`(큰 숫자) + `단백질 먹은/목표` + 칼로리 막대 하나.
   - 누르면: 탄수·지방, 끼니별 구간 막대, 계산 근거(지금의 4개 막대·범례·Disclosure).
   - 아래 칩: `치팅까지 N일 · X 모음`, `상쇄 2/5일 −200`, `오늘 치팅데이 +X`. 칩 → 시트(지금 CheatCard 내용, 설정 바로가기).
2. **지금 할 일 카드 하나**, 우선순위:
   1) 상쇄 제안(과식한 날) → 한 줄 "어제 +900kcal · 나눠 갚기 ›" → 시트에서 선택지·설명
   2) 지금 시간대의 고정식단 미체크(예: 크레아틴) → 바로 체크
   3) 다음 끼니 추천(MealRec) → "먹었어요"
   4) 저녁 단백질 채우기
   - 나머지는 "외 N개 ›".
3. **끼니 타임라인**(지금의 먹은 음식 목록 확장):
   - 끼니 제목 줄: 이름·시간 + kcal + 경고 있으면 `!`만. 누르면 그 끼니 탄단지·% + 경고 문장. 제목의 `+` → 그 끼니 시간으로 음식 추가.
   - 음식 줄: 이름 + kcal. 누르면 탄단지 + `양 수정 · 바꾸기 · 삭제`.
   - **고정식단은 해당 시간 끼니 안에 ☐/☑ 줄**로(별도 카드 없음). 편집은 시트 안 "고정식단 편집".
   - **다음 끼니 추천은 해당 끼니 자리에 흐린 줄**로 미리 보임(2층 카드와 같은 데이터).
4. **+ 음식 추가 → 시트**(전체 높이):
   - 맨 위 검색. 검색 전엔 **최근 · 자주 먹는 음식**(diet-report 선호 재사용)이 먼저, 그 아래 분류 칩(분류·프랜차이즈·식사 코스·내 음식·직접 입력).
   - 음식 고르면 같은 시트에서 양 Stepper + 미리보기 한 줄 + `추가`(주 버튼) / `대체 식단`(보조).
   - 출처·신고는 미리보기 아래 작은 한 줄(지금과 같음), 목록에 없으면 "AI로 찾기".
5. 헤더: `식습관` 버튼 유지(나중에 MY 영양 카드로 이동).

**구현 메모**: `food.tsx`(323줄)를 `nutrition-summary.tsx` · `now-card.tsx`(우선순위 선택) · `meal-timeline.tsx` · `food-add-sheet.tsx`로 분리. `groupMeals`에 고정식단·추천 줄을 끼워 넣는 함수 추가. 기존 `CheatCard` 내용은 시트로 이동.

## 3. 오늘 탭
지금도 대체로 3층 구조(PlanView: 제목·메타·시작 버튼·운동 줄 펼침 → 힌트 한 줄 → 오늘 활동 → 회복도 Disclosure). 손볼 것만:
- **메타 줄 줄이기**: `5개 · 18세트 · 약 60분`만. `루틴 이름`·`컨디션 반영`은 제목 옆 칩, `오늘 N세트 완료`는 진행 막대로.
- **힌트·디로드·회복 경고(notice)를 2층 카드 하나로 통합**(지금은 notice와 HintRow가 따로). 코치 엔진 제안도 여기로.
- **운동 줄**: 접힌 상태 = 이름 · 세트 · 권장 kg×회(지금과 같음). 펼침의 `회복 % · 반복 범위 · 이번 주 N/M세트`는 유지.
- **회복도**: Disclosure 9칸 → 요약 한 줄 "회복 중: 가슴·삼두 (수요일부터)" + 누르면 지금의 9칸. 회복 100%인 부위는 기본 숨김.
- 추가 블록(코치 설계)이 생기면 운동 목록 아래 블록별 접이식 섹션(`기능성 15분`, `스트레칭 10분`).

## 4. 유산소 탭
상태별 화면 전환은 좋음. 대기 화면만 정리:
- **대기**: 종류 칩 → 모드(자유/인터벌/스프린트) → 큰 시작 버튼. `음성 안내 …` 줄은 시작 버튼 아래 작은 링크 하나(`옵션 ›`)로.
- **아래 기록 10개 목록 → 이번 주 요약**: 요일별 거리 막대 + "이번 주 12.4km · 3회". 막대(요일) 누르면 그날 기록, `전체 기록 ›`은 기록 탭으로. 개별 기록은 이미 기록 탭 타임라인에 있으므로 중복 제거.
- 스프린트 결과 카드는 지금처럼 2층(방금 결과) 자리.
- 실내·기타 유산소(CardioPanel)도 같은 원칙: 종류·강도·시간 3개만 보이고 기계 칼로리 등은 펼침.

## 5. 기록 탭
- 지금 `타임라인 / 하루 회고 / 주간 볼륨` 세그먼트 3개 → **하루 하나의 화면**:
  - 1층: 하루 회고 요약 한 줄(소모 vs 섭취, 운동 요약) — 누르면 지금의 하루 회고 전체.
  - 3층: 하루 타임라인(지금 그대로) + 걸음 막대.
- **주간 볼륨 → MY 탭 운동량 카드**로 이동(같은 `weeklySignals`). 이동 전까지는 기록 탭 오른쪽 위 `주간 ›` 버튼.

## 6. 진행 순서(제안)
1. 영양 탭: 음식 추가 시트 분리 → 끼니 타임라인(고정식단 흡수) → 요약 카드 + 칩 → 지금 할 일 카드
2. 공통 `NowCard`(우선순위 하나) 컴포넌트 → 오늘 탭 notice·힌트 통합
3. 유산소 대기 화면 + 이번 주 요약
4. 기록 탭 세그먼트 정리(주간 볼륨은 MY 구현 때 이동)
- 1~2는 코드만 바뀜 → `npm run update`. 출시 전에 해도 되는 범위(스크린샷 찍기 전에 하는 게 좋음).
