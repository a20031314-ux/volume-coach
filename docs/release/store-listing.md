# 스토어 등록 문구 (한국어)

## 앱 이름 (30자 이내)
볼륨 코치

## 간단한 설명 (80자 이내)
부위별 주간 세트 규칙으로 오늘 운동을 추천하고, 웨이트·러닝·걸음을 하루 타임라인으로 기록해요.

## 자세한 설명 (4000자 이내)
규칙만 정해두면, 그날 할 운동은 앱이 맞춰줍니다.

볼륨 코치는 "부위당 주 12~18세트, 부위당 2종류 이상, 같은 부위는 하루 이상 쉬기"처럼 내가 정한 규칙과 회복 상태를 보고 오늘 할 운동을 추천해요. 정해진 루틴을 그대로 따르는 방식도 고를 수 있어요.

■ 나에게 맞춘 시작
• 목표, 경력, 주 운동일, 운동 시간, 장비(헬스장·덤벨·맨몸)를 고르면 추천 루틴을 만들어요
• 턱걸이·바벨 운동 경험, 불편한 동작을 체크하면 할 수 있는 운동으로만 추천해요
• 건너뛰면 기본 추천 루틴으로 바로 시작

■ 오늘 할 일
• 부위별 회복도와 주간 볼륨을 보고 오늘 할 부위·운동·세트를 제안
• 벤치가 차 있으면 다른 운동으로 바꾸고, 기록하면 남은 주간 볼륨이 다시 계산돼요

■ 웨이트 기록
• 운동 시작 → 운동별 → 세트별(무게·횟수) → 끝, 타임라인으로 기록
• 세트 사이 휴식 타이머
• 주간 볼륨으로 부위별 범위 안에 있는지 한눈에

■ 러닝·걷기·등산
• 화면을 꺼도 GPS로 거리·페이스 기록
• 인터벌 모드(예: 4분 달리기 / 3분 회복)와 음성 안내
• 달리는 중 실시간 속도 그래프와 목표 페이스 범위, 벗어나면 음성 알림
• 지도 경로, 고도·오르막, 경사 보정 페이스
• 그래프 구간을 드래그해 확대하고, 지도와 그래프를 눌러 같은 지점을 확인

■ 하루 타임라인
• 웨이트·러닝·걸음을 하루 시간순으로
• iPhone 건강 앱 / 헬스 커넥트 연결 시 15분 단위 걸음 수와 걷는 속도

■ 영양·신체
• 제지방량 기준 단백질 목표와 하루 칼로리
• 인바디 기록 또는 직접 입력

■ 내 기록은 내 폰에
• 가입 없이 사용 가능, 기록은 휴대폰에 저장
• 가입하면 여러 기기 동기화, 언제든 계정 삭제

추천은 일반적인 운동·영양 가이드에 기반한 참고용입니다. 부상이나 질환이 있다면 전문가와 먼저 상의하세요.

## 카테고리
건강/운동

## 태그 후보
운동 기록, 헬스, 웨이트 트레이닝, 러닝, 인터벌, 루틴

## 출시 노트 (첫 버전)
첫 버전입니다. 규칙 기반 운동 추천, 웨이트·러닝 기록, 하루 타임라인을 사용할 수 있어요.
